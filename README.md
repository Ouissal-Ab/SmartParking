# Smart Parking

Application web pour réserver une place de parking en ligne.

## Fonctionnalités

- Voir les parkings et les places libres sur une carte
- Réserver une place et payer en ligne
- Recevoir un reçu PDF avec un QR code
- Espace administrateur pour gérer les parkings, les réservations et les utilisateurs
- Détection des places libres à partir d'une vidéo (OpenCV)

## Technologies

- Backend : Java, Spring Boot, PostgreSQL
- Frontend : Next.js, TypeScript
- Détection : Python, OpenCV

## Tests et qualité

- Tests des API avec Postman
- Tests automatisés de l'interface avec Selenium 
- Analyse de la qualité du code avec SonarQube
